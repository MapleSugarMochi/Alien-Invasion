# 开发与验收记录

日期：2026-10-07。技术基线：Python 3.13.x、pygame==2.6.1、1280×720、目标 60 FPS。

## P0 — 需求与工程基线

已核对 Development Documentation.md、Game Design.md、Game Development Guide.md。基础范围固定为菜单、输入、基础射击、生存、三类敌机、12 波、陨石、定时回血、Boss、胜负与重开；P5 基础验收后再加入 Q/E/X 扩展。

关键规则一致：WASD 按屏幕移动；玩家 100 生命、速度 340；特殊武器三格、5 秒；补给每 7 秒（基础仅回血，扩展三类等概率）；支援 7.5 秒、五轮、Boss 每次最大生命 10%；暂停冻结游戏时间；同帧双亡失败优先。12 波共 118 架普通敌机。

采用开发文档 8.4 的实现建议，包括敌弹半径 4、稳定目标 ID、整数十分之一能量、统一截止时间和轨迹检测。无需新增玩法决策。G01–G16 与 U01–U12、M01–M10 的追踪沿用开发文档；评分要求与开发选择继续区分，不推算成绩。

验证：文档交叉核对通过；实际解释器 Python 3.13.9。尚未建立游戏入口，不将运行或试玩记为通过。原始评分材料、表单和报告模板保留。

下一阶段：P1 窗口、对象显示、输入与退出。

## P2 — 基础射击与生存

实现基础子弹（10 / 0.12 秒 / 900 速度与射程）、共用冷却、生命与 0.8 秒无敌、接触推开、一次击杀结算、陨石挡敌弹、相对运动轨迹最早命中、寿命／射程／屏幕裁切、Esc 和失焦暂停。恢复需重新按左键，HUD 点击不射击。

验证：6 项 unittest 通过；真实 SDL 窗口检查通过射击、受伤、暂停冻结、恢复清输入与退出；compileall 通过。首次复测的窗口脚本对零时长更新做了不成立的假设，已改为实际经过时间检查并复测通过。截图：docs/evidence/p2-window.png、p2-paused.png。正式 P1 窗口已正常结束，无残留运行会话。

## P3 — 普通敌群与场景资源

实现配置驱动三类敌机、顶部／侧面路线、停留与离场、瞄准／扇形敌弹、12 波交错生成与上限、3 秒休息、大小陨石与 0.6 秒预警、7 秒回血调度、满血不消耗和 10 秒生命周期、第 12 波陨石预约取消与清场。waves.py 承担生成队列实际职责。

验证：11 项规则测试通过，覆盖三难度各 118 架自然离场、满额保留队列、掉落时间边界、停留时长和清场取消。真实窗口基础输入回归通过。标准自动输入完整普通关卡：151.25 游戏秒，118 架生成、102 击杀、生命 100，到达 Boss 前准备。事件与阶段画面：docs/evidence/standard-pilot-run.json 等。自动输入只使用移动、瞄准、开火，没有跳波、无敌或改写生命；以加速墙钟运行，不作为人工通关／手感证据。初始简易输入策略在第 8 波失败，改进检查工具的躲避策略后通过，游戏数值未改。测试的简单侧入波次期限从 60 改为 120 秒，避免误把慢速上限行为判为无限等待。
