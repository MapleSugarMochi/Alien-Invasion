# 开发与验收记录

日期：2026-10-07。技术基线：Python 3.13.x、pygame==2.6.1、1280×720、目标 60 FPS。

## P0 — 需求与工程基线

已核对 Development Documentation.md、Game Design.md、Game Development Guide.md。基础范围固定为菜单、输入、基础射击、生存、三类敌机、12 波、陨石、定时回血、Boss、胜负与重开；P5 基础验收后再加入 Q/E/X 扩展。

关键规则一致：WASD 按屏幕移动；玩家 100 生命、速度 340；特殊武器三格、5 秒；补给每 7 秒（基础仅回血，扩展三类等概率）；支援 7.5 秒、五轮、Boss 每次最大生命 10%；暂停冻结游戏时间；同帧双亡失败优先。12 波共 118 架普通敌机。

采用开发文档 8.4 的实现建议，包括敌弹半径 4、稳定目标 ID、整数十分之一能量、统一截止时间和轨迹检测。无需新增玩法决策。G01–G16 与 U01–U12、M01–M10 的追踪沿用开发文档；评分要求与开发选择继续区分，不推算成绩。

验证：文档交叉核对通过；实际解释器 Python 3.13.9。尚未建立游戏入口，不将运行或试玩记为通过。原始评分材料、表单和报告模板保留。

下一阶段：P1 窗口、对象显示、输入与退出。

## P1 — 启动、画面与基础输入

已实现 main/game/entities/render/settings 的最小职责划分，固定窗口、滚动星空、中央玩家和外星敌机、WASD、归一化移动、鼠标朝向与准星。图形明确为阶段占位。

验证：Python 3.13.9 / Pygame 2.6.1 安装成功；compileall 通过；从项目外目录执行 tools/check_window.py 通过，在真实 Windows SDL 窗口验证移动、朝向、重合准星、边界和退出。computer-use 检查正式入口窗口，玩家和中央敌机可见。截图：docs/evidence/p1-window.png。尚未制作手动操作录像，不将其记为已有证据。

## P2 — 基础射击与生存

实现基础子弹（10 / 0.12 秒 / 900 速度与射程）、共用冷却、生命与 0.8 秒无敌、接触推开、一次击杀结算、陨石挡敌弹、相对运动轨迹最早命中、寿命／射程／屏幕裁切、Esc 和失焦暂停。恢复需重新按左键，HUD 点击不射击。

验证：6 项 unittest 通过；真实 SDL 窗口检查通过射击、受伤、暂停冻结、恢复清输入与退出；compileall 通过。首次复测的窗口脚本对零时长更新做了不成立的假设，已改为实际经过时间检查并复测通过。截图：docs/evidence/p2-window.png、p2-paused.png。正式 P1 窗口已正常结束，无残留运行会话。

下一阶段：P3 三类敌机、全部 12 波、陨石预警和每 7 秒回血补给。

## P3 — 普通敌群与场景资源

实现配置驱动三类敌机、顶部／侧面路线、停留与离场、瞄准／扇形敌弹、12 波交错生成与上限、3 秒休息、大小陨石与 0.6 秒预警、7 秒回血调度、满血不消耗和 10 秒生命周期、第 12 波陨石预约取消与清场。waves.py 承担生成队列实际职责。

验证：11 项规则测试通过，覆盖三难度各 118 架自然离场、满额保留队列、掉落时间边界、停留时长和清场取消。真实窗口基础输入回归通过。标准自动输入完整普通关卡：151.25 游戏秒，118 架生成、102 击杀、生命 100，到达 Boss 前准备。事件与阶段画面：docs/evidence/standard-pilot-run.json 等。自动输入只使用移动、瞄准、开火，没有跳波、无敌或改写生命；以加速墙钟运行，不作为人工通关／手感证据。初始简易输入策略在第 8 波失败，改进检查工具的躲避策略后通过，游戏数值未改。测试的简单侧入波次期限从 60 改为 120 秒，避免误把慢速上限行为判为无限等待。

下一阶段：P4 Boss 三阶段、真实规则胜负、统计和重开。

## P4 — Boss 与完整关卡

实现清场后的 1.5 秒警告、Boss 入场保护、三阶段弹幕与瞄准连射、炮口预警、1 秒过渡和旧任务取消；统一整帧失败优先、Boss 接触例外、结算统计、R 重开与结束补给清理。

验证：17 项规则测试通过，包括阈值边界、连射中断、跨阈值、过渡不续时、两种伤害顺序及跨内部小步双亡。真实窗口基础回归通过。标准完整自动输入胜利：183.817 游戏秒、103 击杀、26800 分、118 普通敌机；不输入自然失败：29.45 秒。均未使用跳波、无敌或改生命，结果与事件已保存；属于实际 SDL 渲染下的自动规则运行，不声称人工试玩或 4–6 分钟平衡目标已达成。

下一阶段：P5 正式菜单、操作说明、三难度、暂停／结算入口与基础版本验收。

## P5 — 菜单、难度与基础版本

实现正式主菜单、中文说明与三难度选择、暂停继续／重开／返回、结算重开／返回、鼠标与键盘入口。难度配置作用于生命、移动、敌弹速度、频率、伤害、场内上限与陨石压力；基础参数不重复叠乘。

验证：20 项 unittest 通过，包含实际移动与发弹差异、菜单命中、重开和换难度。发现 0.5 秒入场等待的浮点边界使第一发延后一个小步，已加容差并按敌机射击截止时间拆步。真实窗口菜单／中文／输入回归通过；三难度从正式菜单动作启动，无跳波／无敌的自动输入均完整获胜（简单 176.583、标准 183.783、困难 209.867 游戏秒），自然失败也均已记录（57.783 / 29.45 / 22.233 秒）。相关 JSON 和截图位于 docs/evidence；人工手感、完整实时录像与 4–6 分钟调优仍待 P9，不标为通过。

基础范围完成，实现与自动规则／窗口证据通过；P5 提交保留为基础版本恢复点。当前仍只掉回血。下一阶段：P6 Q/E、三格充能、导弹／电弧与三种等概率补给。

验证：34 项规则测试、真实窗口和完整标准玩法回归通过。检查最终 Boss／弹丸／补给／HUD 画面，中文和图标可读，透明角落 alpha=0。check_resources 实际载入、依次播放 9 音效，格式与峰值检查通过（峰值 0.267–0.313）；真实音频后端初始化成功。强制不可用音频驱动后重复检查通过（audio=False），缺 BGM 正常运行，音量独立且重开保留。音效播放、峰值和并发限制已验证；听感舒适度仍需开发者试听，未声称完成主观听感评价。
