# Alien Invasion 项目评价内容

日期：2026-10-07。实现：Python 3.13.9、Pygame 2.6.1、Windows 11。个人独立项目；不改写原始模板中的历史年度、日期或 Group Project 标识。本文对应原模板的三个问题，供后续填写可验证的 Word 报告。

## What were the most valuable parts of the project

最有价值的成果是可实际运行的完整游戏流程：从菜单选择三种难度，使用 WASD 与鼠标战斗，完成 12 波后进入三阶段母舰战，胜负结算后能够重开或返回。基础版本保存在 Git 标签 baseline-p5；Q/E 特殊武器、三类补给、战斗能量和 X 场外支援作为明确的额外组件实现。

代码按规则、对象、攻击、显示、配置、资源和生成队列划分。Enemy.create 复用三类敌机配置；WeaponController 统一冷却；Game.apply_damage/finalize_kill 统一实际伤害与一次计分；geometry.moving_hit 复用高速弹丸的相对运动检测；SupportController 使用有限轮次与稳定目标 ID。

已建立规则测试、真实 SDL 窗口检查和完整自动输入运行记录。自动操作通过正常输入与真实伤害规则，未使用无敌、跳波或改写生命；加速运行和实时运行分别标注。图集与原创声音随源码保存，资源路径从程序目录解析。关键边界的修复均有回归测试。

## How could the project be improved

标准局的 4–6 分钟调优目标仍需人工试玩数据。自动精准操作局更短，不能直接推断初次玩家的真实时长；因此尚未擅自改变已确认的波次、生命和补给规则。后续应记录人工胜利／失败局时长、死亡原因和 Q/E/X 使用情况，再决定是否调优，并同步设计与回归测试。

音效的格式、峰值、播放接口和并发限制已验证，听感舒适度仍需开发者试听。BGM 留待开发者提供并记录来源。课程演示视频和最终 Word 评价报告尚未完成；本环境的 Word 渲染器缺少 soffice.exe，未输出未经排版验证的 Word 文件。原始模板与评分材料保留。

## What have you learnt from the project

实现过程表明，时间规则需要与渲染帧数分开。统一游戏时间和截止事件使暂停能够冻结无敌、掉落、武器替换、Boss 过渡和支援；小步与截止时间拆分减少卡顿及浮点边界带来的重复或延后。伤害按实际扣血回能，统计与死亡在统一入口结算，避免过量伤害和重复击杀产生错误奖励。

对象行为与显示分离使几何占位能够替换为最终精灵而不改变碰撞；不同难度通过同一配置和规则产生实际速度、频率与伤害差异。规则测试证明复杂边界，窗口与真实规则流程证明各模块能够协同工作，人工试玩则负责操作体验、音量和难度平衡；三类证据不能相互冒充。
